# Workspace language

Use these terms in navigation, status lines and confirmation messages. A contact's eligibility is specific to the audience and the purpose of the message.

| Term | Meaning in the workspace |
| --- | --- |
| People | The place to find contacts, permission and opt-outs. |
| Contact | One person's record in the workspace. |
| Contact list | The community audience after permission, opt-out and deliverability checks. |
| Event registrants | Contacts registered for one event. A reserved place can lack a contact number. |
| Message | The text the user writes. One outgoing message can reach many contacts. |
| SMS segment | One unit of SMS usage. Personalization and encoding can change the number used. |
| Draft | An unfinished message saved on this device for this account and workspace. |
| Scheduled | A message waiting for its scheduled time. |
| Automatic reminder | A scheduled message generated from an event reminder rule. |
| Held for review | A message that needs attention before it can continue. |
| Accepted by provider | The provider acknowledged a submission. |
| Not submitted | A contact's text did not reach the provider. Show the reason when known. |
| Delivered | A positive delivery receipt was recorded. |
| Not delivered | A terminal failure receipt was recorded. |
| No receipt yet | The provider accepted the text and a final receipt is outstanding. |
| Opted out | An opt-out prevents further texting. Keep the contact record. |
