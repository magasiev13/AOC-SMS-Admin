# Twinevia workspace design

The home screen answers “What needs my attention today?” Messages follows the lifecycle of an outgoing text. Conversations holds individual replies. People holds contact records and permission. Events connects the roster, reminders and follow-up for one gathering. Settings, help and account controls stay outside primary navigation.

The wireframes use illustrative names, counts and statuses. Wide screens align message, status and action on a ruled row. Phones put status immediately below the name and keep five destinations within reach of a thumb. Blue marks the main action and active destination. Each delivery and permission status has a text label.

**Writing a message.** Choose who, write the text, then choose when. Keep the estimate and review action in reach. Final review freezes the audience and displays the reviewed cost. Saving and restoring an unfinished message belongs to the current browser, account and workspace.

**Reading a reply.** The initial view shows the conversation list. Opening a name reveals the thread, its reply box and a menu for contact actions. A reaction attaches to its message and a STOP appears as a status change in the record.

**Following up after an event.** Open the latest event, check reserved places and review its automatic reminders before preparing a feedback invitation. Keep the roster and delivery evidence visible to the roles that use them.
